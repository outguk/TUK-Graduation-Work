**전체 기능 설명**

문장 단위 분석: 텍스트 파일로부터 문장을 분리하여 평가 단위로 삼는다

형태소 분석: KoNLPy의 Okt와 Kkma를 사용해 문장 내 품사를 분석한다

높임말 평가: 비격식적 종결어미(EFN, EFQ 등)를 감지하여 문체의 일관성과 격식 유무를 판단한다

추측 표현 감지: "수 있다", "일 것이다" 등 추측이나 가능성을 나타내는 표현을 형태소 패턴 기반으로 판별한다

어휘 다양성 평가: 중복되지 않은 의미 있는 단어의 비율을 계산해 어휘 폭을 측정한다

주어-서술어 호응 검사: 명사+조사+서술어 조합이 존재하는지를 기반으로 문장 구조의 완결성을 평가한다

발표 시간 대비 분량 체크: 사용자로부터 입력받은 시간(분)에 따라 권장 분량(문자 수) 범위 내인지 확인한다

비속어 감지: badword_check 모델을 활용해 문장 내 부적절한 표현 유무를 감지한다

오타 감지: 자음/모음 단독 문자를 탐지하여 오타 가능성을 알려준다

반복 단어 탐지: 텍스트 내 자주 사용된 단어를 집계해 반복 여부를 파악한다 -> 아직 미완성

**기능 구현 방식**

Kkma를 통한 종결어미 태그 분석으로 높임말 사용 여부를 감지한다. 비격식적인 어미가 포함된 경우 감점 대상이 된다

추측 표현은 Kkma의 품사 태그 시퀀스를 기반으로 설정된 패턴들과 비교하여 탐지한다. 실제 사용 사례에 기반하여 패턴이 구성되어 있으며, 오탐을 줄이기 위해 반복적인 테스트를 통해 정제하였다

어휘 다양성은 Okt 분석기를 활용해 의미 없는 조사나 기호를 제거한 후, 전체 단어 수 대비 고유 단어 수 비율을 계산한다. 추후 핵심어 제거 기능과의 연계도 가능하다

주어-서술어 구조 검사는 명사+조사 구조와 동사/형용사의 존재 여부를 함께 확인하여 기본 문장 구조의 충족 여부를 평가한다

발표 시간은 사용자 입력을 기반으로 계산되며, 글자 수 기준(분당 약 270~320자)을 바탕으로 적정 분량 여부를 판단한다

비속어는 badword_check의 모델로 전처리된 문장을 예측하여 판단되며, 결과가 1이면 비속어 포함으로 처리된다

오타 및 반복 단어는 단순 문자 기반 탐색 및 빈도 분석을 통해 감지된다

**평가 방식 및 점수 계산**

총점은 100점 만점이며, 각 항목별 배점은 다음과 같다:

높임말 사용: 20점

추측 표현: 20점

어휘 다양성: 20점 -> 아직 미완성

주어-서술어 호응: 20점

발표 분량 적정성: 10점

비속어 사용 여부: 10점

**감점 방식**

높임말, 추측 표현, 주어-서술어 호응, 비속어는 위반 문장 1개당 1점씩 차감된다. (단, 0점 미만으로는 내려가지 않음)

어휘 다양성은 비율로 계산되며 (고유 단어 수 / 전체 단어 수) * 20점 방식으로 점수를 부여한다 -> 아직 미완성

분량 적정성은 입력된 발표 시간에 기반한 권장 문자 수를 기준으로 실제 대본 길이를 비교하여 초과/미달 비율만큼 감점되며, 권장 범위 내에 있을 경우 만점을 부여한다
