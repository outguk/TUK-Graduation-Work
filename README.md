# 스크립트 피드백버전

### 주요 평가 항목
1. **높임말 사용 (격식 여부)**
2. **추측 표현 포함 여부**
3. **주어-서술어 호응 관계**
4. **발표 시간 대비 적절한 분량**
5. **비속어 포함 여부** (korcen + 사용자 정의 사전 사용)
6. 어휘 다양성 - 삭제
7. 오타(자음/모음 단독 문자) 검사
8. 반복 단어 빈도 분석 (코드상 미완성, 현재 비활성화)

## 구성 및 실행 방법

### 1. 환경 설정
KoNLPy, korcen와 같은 필수 라이브러리 설치
나머지는 environment.yml 참고

### 2. 파일 구조
필요한 파일 output_transcription.txt,script_feedback_korcen.py,custom_profanities.txt
```
TUK-Graduation-Work/
└─ output_transcription.txt # (대본 텍스트)
└─ scriptanalysis/
   ├─ script.py , script_feedback.py -> 추후 비속어 라이브러리를 바꾸거나 어휘 다양성을 다시 적용할때 사용, 현재는 사용하지않음
   ├─ script_feedback_korcen.py  # (최종 평가 스크립트)
   └─ custom_profanities.txt # (사용자 정의 비속어 사전,korcen로 필터링 되지 못한 단어들이나 신조어, 새롭게 필터링 해야하는 단어 등록)
   
```

### 3. script_feedback_korcen.py 실행하기
1. `output_transcription.txt` 파일 안에 대본 내용을 넣음
2. `custom_profanities.txt` 파일 안에 추가하고 싶은 비속어나 불필요한 단어를 한 줄에 하나씩 작성
3. 발표 시간을 (분 단위) 입력하면, 분석 결과가 콘솔에 피드백 형식으로 출력됨

## 전체 기능 설명

1. **문장 단위 분석**  
   텍스트 파일에서 문장을 분리(마침표, 줄바꿈 등)하여 평가 단위로 삼습니다.

2. **형태소 분석**  
   KoNLPy의 `Okt`, `Kkma` 형태소 분석기를 사용해 문장 내 품사를 분석합니다.

3. **높임말 평가**  
   Kkma 결과에서 비격식 종결어미(EFN, EFQ 등) 감지 → 문체 일관성과 격식 유무 파악
   → 비격식 문장 발견 시 리스트업

4. **추측 표현 감지**  
   "수 있다", "일 것이다" 등 추측 표현을 형태소 패턴(패턴 리스트) 기반으로 판별

5. **주어-서술어 호응 검사**  
   간단히 (명사+조사) 구조와 서술어(동사·형용사) 존재 여부 확인

6. **발표 시간 대비 분량 체크**  
   사용자로부터 **발표 시간(분)**을 입력받아,
   분당 270~320자 권장 기준으로 **글자 수**를 비교 → 너무 많거나 적으면 피드백

7. **비속어 감지 (korcen + 사용자 정의 사전)**  
   - **korcen**: KKMA 명사 목록을 korcen.check(...)로 검사
   - 추가로 **`custom_profanities.txt`**에서 줄 단위로 로드한 사용자 정의 목록은 **문장 전체** substring 검사 → (예: "존나" 등 korcen에 없는 단어 필터링)

8. **오타 감지**  
   자음·모음 단독 문자(예: ㄱ, ㅏ ㄴ , ㅑ 등)가 문장에 있으면 오타 가능성으로 판단, 혹은 추후 stt를 통한 대본 입력시 정확도 향상

9. 반복 단어 탐지 (제거)  
   단어 빈도 카운트는 작동하지만, 현재 출력/평가 부분은 주석 처리된 상태-> 어휘 분석 불가능, 삭제

## 평가 방식 및 점수 계산(구버전)
- 과거에는 **총 100점** 방식이었으나, 현재 코드는 점수 대신 피드백 형태로 안내
- 향후 어휘 다양성 등 보완 시, 점수 계산 로직을 재도입 가능

## 변경 사항 요약
- (구) badword_check 모델 → (신) korcen + 사용자 정의 사전
- **어휘 다양성** 제거
- **비속어 감지 로직**: KKMA 명사만 korcen에 전달 + 사용자 사전 substring 검사 (둘 중 하나라도 True → 비속어)
- 실행 시 **발표 시간**(분) 입력 후 콘솔 피드백
